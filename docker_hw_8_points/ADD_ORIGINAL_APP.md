# ВАЖНО: добавьте оригинальный каталог app

Этот архив содержит **конфигурацию Docker на уровень 8 баллов**, но не исходники
приложения. По фото не видно содержимое папки `app`, и доступ к ссылке
на репозиторий-шаблон не получен.

1. Откройте исходный репозиторий, показанный на фото.
2. Перейдите в `2026/amcs/year_1/hw_3/app`.
3. Скачайте исходный репозиторий архивом (Code -> Download ZIP).
4. Скопируйте именно его папку `app` в корень этого проекта рядом с Dockerfile.
5. Не изменяйте содержимое исходного приложения.
6. В `app/README.md` (или другой инструкции из `app`) найдите команду запуска,
   требуемые зависимости, название переменной приветствия, порт и убедитесь,
   что `Dockerfile`, `.env.example` и `compose.yaml` им соответствуют.

Этот набор файлов предполагает **Python-приложение** с `requirements.txt`
или `pyproject.toml`. Если в исходниках другой стек (Node, Go и т.п.),
то Dockerfile и запуск нужно адаптировать — не пытайтесь сдавать без проверки.

Критично: до копирования `app/` запуск не будет работать.
